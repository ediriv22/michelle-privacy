1. Dati Raccolti

MICHELLE raccoglie i seguenti dati per fornire il servizio di automazione dei contenuti:

  • Token di accesso: Token di accesso a lungo termine per Instagram e Facebook (per autorizzare il posting automatico)
  • Metadati dei contenuti: ID post, caption, hashtag, URL immagini pubblicate
  • Dati di stato: Stato dei carousel, timestamp di creazione e pubblicazione, ID post
  • Log di errori: Messaggi di errore per debugging e miglioramento del servizio
  • Dati di utilizzo: Numero di post generati, topic utilizzati, timing delle pubblicazioni

2. Come Utilizziamo i Dati

  • ✓ Autorizzare il posting automatico su Instagram e Facebook
  • ✓ Tracciare lo stato dei carousel e dei post
  • ✓ Rilevare e correggere errori
  • ✓ Migliorare l'algoritmo di generazione dei contenuti
  • ✓ Mantenere registri storici dei post pubblicati

3. Sicurezza dei Dati

I dati sensibili (token di accesso) sono archiviati in:

  • Variabili d'ambiente protette (.env)
  • Database SQLite locale con accesso ristretto
  • Non vengono mai inviati a server esterni (eccezione: Meta e Replicate API come necessario)

MICHELLE non condivide dati con terze parti, eccetto per:

  • Meta (Instagram/Facebook): Token e dati di post (necessario per il servizio)
  • Replicate/Flux: Prompt per la generazione immagini (nessun dato personale)
  • Cloudflare R2: URL immagini per CDN (pubbliche)

4. Diritti dell'Utente

Hai il diritto di:

  • 📋 Accesso: Richiedere una copia dei tuoi dati
  • 🗑️ Eliminazione: Richiedere l'eliminazione completa di tutti i tuoi dati
  • ✏️ Rettifica: Corregere dati inesatti
  • ⚙️ Portabilità: Richiedere i tuoi dati in formato leggibile

5. Eliminazione dei Dati

Per richiedere l'eliminazione dei tuoi dati:

  1. Invia un'email a 296edi@gmail.com con oggetto "[DATA_DELETION_REQUEST] MICHELLE"
  2. Specifica quali dati desideri eliminare (token, cronologia post, log, etc.)
  3. Conferma la tua identità (email associata all'account Instagram/Facebook)
  4. Riceverai conferma dell'eliminazione entro 30 giorni lavorativi

Nota: L'eliminazione di token revocherà l'accesso di MICHELLE al tuo account Instagram/Facebook.

6. Conservazione dei Dati

  • Token: Conservati fino a revoca o disconnessione
  • Post history: Conservati per 1 anno o fino a richiesta di eliminazione
  • Log di errori: Conservati per 90 giorni per debugging
  • Database locale: Eliminato se richiesto dall'utente
